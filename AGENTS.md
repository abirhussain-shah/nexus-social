# Nexus Social — Workspace Rules & Workflow

## Mandatory Mockup-First Approval Protocol
1. **Always Provide Mockup First**:
   - Before implementing any new feature, UI screen, or visual adjustment, the assistant must **always generate and present a high-fidelity visual mockup** (MOC) first.
2. **Explicit User Approval Gate**:
   - **Do NOT begin implementation until the user explicitly agrees/approves.**
   - The assistant must present the mockup, describe the design and flow, and pause for user sign-off.
3. **Implementation Standards**:
   - Built on **.NET 8 (`net8.0`)** with ASP.NET Core SignalR and 15-minute inactivity session management.
   - Real users only (no dummy/seed accounts).
   - Real-time live texting and WebRTC audio/video calling.
   - Fully responsive design with dedicated mobile navigation (`< Chats` back button).
